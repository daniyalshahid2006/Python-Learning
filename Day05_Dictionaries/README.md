# Contact Book Management System

A simple Contact Book Management System built using Python.

## Features

- Add a contact
- View all contacts
- Search for a contact
- Update contact information
- Delete a contact
- Count total contacts

## Technologies Used

- Python
- Dictionaries
- Functions
- Loops
- Conditional Statements

## Future Improvements

- File Handling (JSON)
- Persistent Data Storage
- Better User Interface
- Database Integration
