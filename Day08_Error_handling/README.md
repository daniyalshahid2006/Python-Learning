# Banking System (Python)

A simple banking system built using Python and CSV file handling.

## Features

- Create a new account
- User login system
- Deposit money
- Withdraw money
- Check account balance
- Delete account
- View all accounts
- Error handling using try/except

## Technologies Used

- Python
- CSV module
- File handling
- Exception handling

## How It Works

The program stores account information in a CSV file:

- Account Number
- Username
- Password
- Balance

When a user performs actions like deposit or withdrawal, the CSV file is updated automatically.
