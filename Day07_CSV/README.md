# 📚 CSV Student Management System

A simple Student Management System built in Python using the built-in `csv` module.

## ✨ Features

- ➕ Add Student
- 📋 Show All Students
- 🔍 Search Student
- ✏️ Update Student
- ❌ Delete Student
- 📊 Count Total Students

## 🛠️ Technologies Used

- Python 3
- CSV Module

## 📂 File Structure

```
students.csv
main.py
README.md
```

## ▶️ How to Run

1. Clone the repository.
2. Open the project in PyCharm or VS Code.
3. Run the Python file.
4. Use the menu to manage student records.
