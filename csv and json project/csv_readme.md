# Student Management System - CSV

A console-based Student Management System built with Python, OOP, and CSV file handling.

## Features

- Add a student
- Show all students
- Search for a student
- Update student information
- Delete a student
- Count students
- Store student data in a CSV file
- Load existing students from the CSV file
- Uses encapsulation for the phone number

## Concepts Used

- Classes and Objects
- Encapsulation
- Private attributes
- Getters and Setters
- Dictionaries
- Loops
- Conditional Statements
- Functions/Methods
- File Handling
- CSV module
- Exception-free menu-driven program
